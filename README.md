# nutreon-cards
Cópia pública dos cards do blog [Nutreon Ciência](https://www.nutreon.com.br/blog/), servida pelo jsDelivr
(`https://cdn.jsdelivr.net/gh/gabrielscapella/nutreon-cards@main/m/<arquivo>`) para o botão "Postar no Instagram"
anexar as imagens no celular. O workflow `espelhar-cards` lê o sitemap do blog e copia os cards já publicados.
